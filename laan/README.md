# לאן? (`laan`)

אפליקציית אינטרנט (`PWA`) שמלווה קשישים בנסיעה באוטובוס, הוראה אחת בכל פעם.
היא מיועדת לבני 75 ומעלה, דוברי עברית, במכשירי `Android` עם `Chrome`.
כל הוראה נאמרת בקול וגם מופיעה בכתב גדול, בלי מונחים טכניים ובלי הודעות שגיאה.

## הרצה

```
export ANTHROPIC_API_KEY=...
python3 server.py
```

אחר כך פותחים את `http://localhost:8000` בדפדפן.
בלי `ANTHROPIC_API_KEY` האפליקציה עדיין עובדת, באמצעות מסלולי הגיבוי שלמטה.
אפשר לשנות פורט עם המשתנה `PORT`.

## מצב הדגמה

- `?demo=1` מריץ נסיעה מדומה ללא מיקרופון וללא `GPS`, למשל `http://localhost:8000/?demo=1`.
- `&auto=1` לוחץ "כן" אוטומטית אחרי 3 שניות, והדגמה רצה בלי מגע.
- `&speed=2` מקצר את כל ההדגמה לחצי מהזמן.

## בדיקה על טלפון `Android`

המיקרופון והמיקום עובדים רק בהקשר מאובטח (`https` או `localhost`).
לכן דרך `Wi-Fi` ועל כתובת `http` רגילה הם לא יעבדו.

**הדרך המומלצת:** מחברים את הטלפון בכבל `USB`, מפעילים ניפוי באגים, ומריצים:

```
adb reverse tcp:8000 tcp:8000
```

ואז פותחים ב־`Chrome` בטלפון את `http://localhost:8000`.

**חלופה ראשונה:** ב־`Chrome` בטלפון נכנסים אל `chrome://flags/#unsafely-treat-insecure-origin-as-secure`,
מוסיפים את כתובת המחשב (למשל `http://192.168.1.20:8000`), מפעילים ומאתחלים את הדפדפן.

**חלופה שנייה:** מנהרת `HTTPS` למחשב, למשל `cloudflared tunnel --url http://localhost:8000`,
ופותחים את הכתובת שהיא מחזירה.

מצב ההדגמה עובד גם על `http` רגיל, כי הוא לא צריך מיקרופון ולא מיקום.

## התקנה למסך הבית

ב־`Chrome` לוחצים על תפריט שלוש הנקודות, ובוחרים "התקנת אפליקציה" או "הוספה למסך הבית".
הסמל "לאן?" יופיע במסך הבית, והאפליקציה תיפתח גם בלי רשת.

## שרתי ביניים ב־`server.py`

הדפדפן מדבר רק עם השרת המקומי, והשרת מדבר עם השירותים החיצוניים:

- `POST /api/destination` ו־`POST /api/where-am-i` פונים אל `Claude`.
- `GET /api/geocode` ו־`GET /api/reverse` פונים אל `Nominatim` לחיפוש כתובות.
- `GET /api/walk` מחשב מסלול הליכה (`routing.openstreetmap.de`).
- `GET /api/plan` בונה מסלול אוטובוס מנתוני `open-bus-stride`.
- `GET /api/health` בודק שהשרת חי ואם יש מפתח.

## גיבוי כשמשהו נכשל

כל כשל, כולל תקלת רשת, זמן קצוב שעבר או תשובה לא תקינה, מחזיר `{"ok": false}`.
האפליקציה עוברת אז בשקט למסלול הקבוע בדיזנגוף, קו 5, בלי הודעת שגיאה למשתמש.
בלי `ANTHROPIC_API_KEY` כל הנתיבים של `Claude` נכשלים באותה צורה, והנסיעה עדיין מושלמת.
