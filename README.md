# נגישות לכולם

כלים דיגיטליים שנבנים קודם כל בשביל מי שהטכנולוגיה בדרך כלל שוכחת: אנשים מבוגרים, אנשים עם ראייה או שמיעה חלשה, ומי שאפליקציה רגילה מלחיצה אותו.

## הפרויקטים

### [לאן?](laan/) — מדריך אוטובוסים למבוגרים

הוראה אחת בכל פעם, בקול ובכתב גדול. האפליקציה מזהה איפה אתה, מוצאת קו ישיר בלי החלפות, מלווה בהליכה לתחנה, סופרת תחנות בנסיעה ומתריעה לפני הירידה. אם הלכת לאיבוד, היא שואלת מה אתה רואה לידך ועוזרת לשלוח לבן המשפחה איפה אתה.

- הרצה והתקנה: [`laan/README.md`](laan/README.md)
- מסמך המוצר: [`laan/docs/product-brief.md`](laan/docs/product-brief.md)

## עקרונות

- משפט אחד, פעולה אחת בכל מסך
- כל הוראה נאמרת בקול וגם מוצגת בכתב
- טקסט מ־32 פיקסלים, כפתורים מ־72 פיקסלים, ניגודיות 7:1
- כשמשהו נכשל, המשתמש לא רואה שגיאה: יש תמיד דרך חלופית
